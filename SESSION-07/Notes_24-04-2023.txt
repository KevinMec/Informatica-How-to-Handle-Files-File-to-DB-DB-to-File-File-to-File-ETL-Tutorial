TABLES
------
1. TABLES ARE IN FORM OF ROWS AND COLUMNS 
EG: CUSTOMERS , LOCATIONS 

2.TABLES LOCATED IN SCHEMA 

3. SCHEMA LOCATED IN DATABASE

4. TABLES WILL NOT HAVE EXTENSIONS 


FILES 
------
1.FILES WILL NOT HAVE ROWS AND COLUMNS 
PPT FILE
WORD FILE
PDF FILE
IMAGE FILE
EXECUTABLE FILE

2. FILES LOCATED INTO DIRECTORIES(FOLDERS)

3. DIRECTORIES OR FOLDERS LOCATED IN FILE SERVER( OPERATING SYSTEM)

4. FILES WILL HAVE EXTENSIONS.
	EG : FILE1.txt , abc.jpg , File2.exe 
	     file3.pdf
	Files will be having size  1KB , 1MB , 1GB


-------------------------------------------------------------------

TYPES OF FILES :

1. STRUCTURED FILES  (FLAT FILES /DATA FILES )
2. SEMI STRUCTURED FILES ( XML FILES / HTML FILES)
3. UN STRUCTURED FILES  ( IMAGE FILES , AUDIO FILES ,VIDEO FILES , WORD , PDF FILES)


by using informatica , we will deal 90% FLAT FILES /DATA FILES
                                    10% XML FILES / HTML FILES


FLAT FILES / DATA FILES.

IF THE DATA COMING IN THE FORMAT OF FILE - FLAT FILE /DATA FILE.

TWO TYLES OF FLAT FILES :

FIXED WIDTH FLATFILE.
DELIMITED   FLATFILE.
